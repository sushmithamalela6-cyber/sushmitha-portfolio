# M Sushmitha - Personal Portfolio

A responsive and accessible personal portfolio created for **Full Stack Development Assignment-1**.

## Technologies
- HTML5 semantic structure
- CSS3 with Flexbox, Grid and media queries
- Bootstrap 5
- JavaScript ES6+
- Bootstrap Icons

## Assignment requirements covered

### 1. HTML5
Sections included:
- Home
- About
- Education
- Skills
- Projects
- Internship Experience
- Certifications
- Contact

Also includes headings, lists, links, an education table, images/visual profile area, and a contact form.

### 2. CSS3 & Responsive Design
- CSS variables
- Box model
- Typography
- Positioning
- Flexbox
- CSS Grid
- Mobile-first media queries
- Responsive cards and tables

### 3. Bootstrap UI
- Responsive navbar
- Bootstrap grid
- Buttons
- Cards
- Forms
- Table
- Alerts
- Responsive utilities

### 4. JavaScript ES6+
Interactive features:
1. Light/Dark theme switching with localStorage
2. Project filtering by category
3. Contact form validation with dynamic success/error messages
4. Back-to-top button
5. Dynamic copyright year

### 5. Validation & Integration
- Required fields
- Email validation
- Minimum length validation
- Dynamic error/success messages
- Accessible labels and ARIA attributes
- Responsive design

## Run locally

Open `index.html` in a browser.

For best results, run a local server:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

## GitHub Pages
Upload the project files to a GitHub repository. Enable GitHub Pages from repository Settings > Pages and select the main branch.
